the receipts

Provenance is an artifact, not a paragraph in a model card.

Each boundary writes the record needed by the next one. Hashes prove identity and integrity; the BOM states exactly what WALDO verified and what the backend reported.

EXPORT.json

Corpus OpenWALDO BOM

Pins the Git revision, selected manifests, sources, licenses, canonical objects, counts, and exported-file hashes.

ORIGIN-BOM.json

Starting-weight identity

Records the immutable repository revision, acquired artifacts, architecture, tokenizer, precision, and provenance gaps of pulled weights.

RUN-BOM.json

Planned and observed run

Writes the immutable plan before execution, then binds backend observations, evaluation, checkpoints, and output hashes afterward.

BOM.json · EU-BOM.json

Release inventory and disclosure

Ships the selected origin or real run with a hashed release inventory and a separate regulatory disclosure projection.

open means the source is open

Weights alone are not enough.

A model is not fully open when its training data and build record disappear. OpenWALDO keeps the data, artifacts, license assertions, origins, and run history connected to the release—so “open” can be inspected instead of merely claimed.
