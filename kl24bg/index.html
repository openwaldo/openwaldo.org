Open Weights. Open Artifacts. Open Licenses. Open Data. Open Origins. OpenWALDO.

An open-weight model without its training data is a binary without source: you can run it, but you cannot inspect it, verify it, or rebuild it. OpenWALDO makes the training data itself the open, shared substrate — curated in git, licensed per shard, verifiable by hash — so a model can finally carry its source.

the checklist

“Open” is five things — and "WALDO" is the checklist.

Labs release weights, withhold everything that made them, and collect the word “open” anyway. WALDO is what open has to enumerate before it’s honest — and each letter is something this project makes verifiable, not aspirational.

open…delivered by
WWeights Every model ships with its bill of materials: the index commit, manifest hashes, and recipe that produced it.
AArtifacts Shards, manifests, and tokenizers are content-addressed objects — the hash is the identity; anyone can verify a byte.
LLicenses Per-shard SPDX labels, faithfully recorded — any downstream consumer can include or exclude by tag.
DData The corpus itself, indexed and anonymously fetchable — the source code of the model.
OOrigins Provenance all the way down: source registries, fetch logs, DCO sign-offs.

A model is open when all five are open. Anything less is a binary with a press release. open(Weights, Artifacts, Licenses, Data, Origins)

why this exists

Open weights is not open source.

The AI industry has spent years arguing about where models come from — which lab, which country, which license on the weights. That gets the threat model half right. The real problem was never where a model comes from. The problem is that nobody can audit what went into it. The fear of closed Western models and the fear of open Chinese ones are the same fear: being forced to trust weights no one can see into.

Open source already won this argument once. Proprietary vendors made identical claims about open code — insecure, unaccountable, impossible to trust — and lost, because source, licenses, and provenance made trust unnecessary: anyone could read the code, and anyone could rebuild it. AI is missing exactly that property. What’s missing isn’t policy — it’s an auditable source of data and the toolchain to build trusted models from it.
