the walkthrough

Train your first model from scratch.

Ten minutes, one machine, full provenance. You’ll clone the public index, verify every byte against its hash, and train a real model whose entire existence — data, licenses, recipe — is on the record.

Set expectations honestly: a ~10M-parameter model trained on a slice of the corpus generates English-shaped babble — grammatical, charming, and meaningless. That’s the correct result at this scale. What you’re really building is the discipline: a model that carries its own bill of materials.

1. Install the toolchain

One Go binary, built from source (binary packages to follow), plus uv — the training harness runs through it with dependencies resolved automatically, so there’s no Python environment to set up.

macOS — install
# prerequisites: git, Go 1.24+, and uv
$ brew install go uv

# build and install the waldo binary
$ git clone https://github.com/openwaldo/waldo.git && cd waldo && make install

# training backend: MLX, auto-detected on Apple Silicon — nothing to configure
Linux — install
# prerequisites: git, Go 1.24+, uv, and the NVIDIA driver for GPU training
$ sudo dnf install golang git   # or apt install golang-go git
$ curl -LsSf https://astral.sh/uv/install.sh | sh

# build and install the waldo binary
$ git clone https://github.com/openwaldo/waldo.git && cd waldo && make install

# training backend: PyTorch, auto-detected on CUDA — add --gpus N for multi-GPU

2. Clone the public index

The checkout is the corpus: small, human-readable metadata in git, with the actual training bytes fetched on demand from federated storage and verified by hash. Consuming it needs no account and no credentials.

the index
$ git clone https://github.com/openwaldo/waldo-index.git && cd waldo-index

3. Trust nothing — verify everything

Before training on a single byte, check the whole tree: every committed shard, against its recorded hash.

verify
$ waldo index verify
checked: 14 index(es), 7 manifest(s); declared 40 shard(s), 497713 docs, 2.8B tokens
bytes:   40 object(s) confirmed present in the store (existence + size; --fetch re-hashes)
ok

4. See what the corpus holds

Tokens, licenses, and the honest training math — including which model size this much data can actually support.

summary
$ waldo index summary
.: 7 corpus(es), 40 shard(s)
  tokens  2.8B (reference-tokenizer estimate)
by license:
  CC-BY-4.0                18 shard(s)      2.0B tokens
  CC0-1.0                   2 shard(s)     86.8M tokens   …
  recommended rung: 90m (~75.7M params) — 37 tokens/param at 1 epoch

5. Create your model

Architecture is chosen at init — preset rungs run from 10m to 405b, or derive a custom shape with --params. For a first model, the 10m rung proves the whole pipeline on any machine.

init
$ waldo model init bookworm --preset 10m

6. Train

Point the model at an index path. Shards fetch anonymously, verify against their hashes, cache locally, and stream into training — and the run pins its bill of materials before the first step.

train — MLX
$ waldo model train bookworm core/books
pretrain  step    12/12 (100.0%)  loss 3.2147  (avg10 3.7903)
done: final loss 3.7903 (held-out 3.4355)
run 1 complete — BOM pinned (1 manifests, index commit 8d04e24c3fbc)
train — PyTorch
$ waldo model train bookworm core/books   # --gpus 8 for a multi-GPU box
pretrain  step    12/12 (100.0%)  loss 3.2147  (avg10 3.7903)
done: final loss 3.7903 (held-out 3.4355)
run 1 complete — BOM pinned (1 manifests, index commit 8d04e24c3fbc)

7. Talk to it — then read its receipts

The chat will babble; the provenance won’t. Export ships the weights with the full ancestry embedded: every run, every manifest, every license, pinned to the exact index commit.

chat & export
$ waldo chat bookworm
$ waldo model export bookworm ~/bookworm-export
  model.safetensors (~9.5M params; provenance embedded in the safetensors metadata)
  model.json
  PROVENANCE.md (2 lineage events, 1 runs)

Where to go from here

  • Bigger rungs — the same commands scale from this laptop toy to GPU servers and clusters; see the growth ladder.
  • Your own tools — waldo index export science --license "CC-BY-*" hands the corpus to any training stack as plain files, filtered to the license profile you choose.
  • Contribute — data you’re allowed to share is one ingest and one pull request away; the community page walks through it.
