Here's WALDO: The AI Source Code

Open Weights. Open Artifacts. Open Licenses. Open Data. Open Origins. OpenWALDO.

Open source AI doesn't truly exist, until now. OpenWALDO is a community-governed corpus and toolchain for contributing, verifying, selecting, and tracing training data — from original source to model bill of materials. If training data is a model’s source code, the source must be open too.

Put data into the commons. Take verified data into a model.

the checklist

"WALDO" is the definition of "open".

Labs release weights, withhold everything that made them, and collect the word “open” anyway. WALDO is what open has to enumerate before it’s honest — and each letter is something this project makes verifiable, not aspirational.

open…delivered by
WWeights Open model releases carry a bill of materials: the starting weights, index commit, manifest hashes, training runs, and recipes that produced them.
AArtifacts Canonical shards and model artifacts are content-addressed — the hash is the identity, and anyone can verify the bytes.
LLicenses License assertions and upstream evidence stay on the record, so downstream consumers can select the exact profile they accept.
DData The corpus itself, indexed and anonymously fetchable — the source code of the model.
OOrigins Provenance all the way down: source references, reviewed ingest evidence, object hashes, and DCO sign-offs.

A WALDO compliant model is open when all five are open. Anything less is nothing more than freeware. open(Weights, Artifacts, Licenses, Data, Origins)

why this exists

It was always about the data.

The AI industry has spent years arguing about where models come from — but the fight was never really about the models. It’s about the data and training material behind them. Did a frontier lab pull your work into its training set? Did another lab distill and train from that lab’s models? Nobody can say, because nobody can audit what went into any of them. Every accusation, lawsuit, and ban in AI today is downstream of that one blind spot.

That is exactly what open source is for: clarity, confidence, and assurances — trust through verification, not reputation. And open source has won this argument far more than once. Linux runs every cloud, every supercomputer, and most of the phones on Earth. Apache and Nginx serve the web. Git is how the world writes software. Kubernetes runs its infrastructure, Python is the language AI itself is built in, and GCC and LLVM compile all of it. Each one won the same way: source, licenses, and provenance made trust crystal clear. A truly open, WALDO-compatible model brings that property to AI — every source auditable, every claim checkable, leveraging and furthering the work of others, collaboratively.

no more copies of copies

Get it from the source.

AI is becoming a copy of a copy of a copy — models distill training data from other models, drifting toward model collapse. OpenWALDO brings the sources together in a distributable format that anyone can inspect, audit, and use directly — no distilling from other models, no inheriting someone else’s copy, get it directly, from the source.
